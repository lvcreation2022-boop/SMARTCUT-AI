# SMARTCUT AI — ಮೊದಲ Prototype

ಈ ZIP ಒಂದು Flutter source project. ಇದು ಈಗಲೇ APK ಅಲ್ಲ.

## ಮೊಬೈಲ್‌ನಿಂದ APK ನಿರ್ಮಿಸುವ ವಿಧಾನ
1. ZIP ಅನ್ನು Extract ಮಾಡಿ.
2. GitHub ನಲ್ಲಿ `SMARTCUT-AI` ಎಂಬ repository ರಚಿಸಿ.
3. Extract ಮಾಡಿದ ಫೋಲ್ಡರ್‌ನ ಒಳಗಿನ ಎಲ್ಲಾ ಫೈಲ್‌ಗಳನ್ನು ( `.github` ಫೋಲ್ಡರ್ ಸಹಿತ) repository ಗೆ Upload ಮಾಡಿ.
4. GitHub repository → Actions → `Build SMARTCUT AI APK` → `Run workflow` ಆಯ್ಕೆಮಾಡಿ.
5. Build ಯಶಸ್ವಿಯಾದ ನಂತರ Actions run ಒಳಗಿನ Artifacts ನಲ್ಲಿ `SMARTCUT-AI-APK` ಒತ್ತಿ APK ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ.

## ಈಗಿರುವುದು
- Gallery ಯಿಂದ ವಿಡಿಯೋ ಆಯ್ಕೆಮಾಡುವುದು
- Video preview
- ಭಾಷೆ ಮತ್ತು output ratio ಆಯ್ಕೆ
- AI ಎಡಿಟಿಂಗ್ ಆಯ್ಕೆಗಳ UI

## ಇನ್ನೂ ಸೇರಿಸಬೇಕಿರುವುದು
ನಿಜವಾದ silence detection, multilingual speech-to-text, captions generation, AI B-roll, audio cleanup ಮತ್ತು final video rendering. ಇವು ಈ prototype ನಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವ AI ಫೀಚರ್‌ಗಳಲ್ಲ.
